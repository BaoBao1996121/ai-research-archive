## 意图识别Schema定义

### 输出格式
```json
{
  "intent": {
    "name": "意图名称",
    "confidence": "置信度",
    "entities": [
      {
        "entity": "实体名称",
        "value": "实体值",
        "confidence": "实体置信度"
      }
    ]
  }
}
```

### 字段说明
- **intent.name**：识别出的意图名称，如"查询天气"、"预订机票"等。
- **intent.confidence**：意图识别的置信度，取值范围为0到1。
- **intent.entities**：识别出的实体信息，包括实体名称、实体值和实体置信度。

### 示例
```json
{
  "intent": {
    "name": "查询天气",
    "confidence": 0.95,
    "entities": [
      {
        "entity": "城市",
        "value": "北京",
        "confidence": 0.98
      },
      {
        "entity": "日期",
        "value": "明天",
        "confidence": 0.96
      }
    ]
  }
}
```

- 定期更新和维护Schema，以适应新的业务需求和技术发展。
