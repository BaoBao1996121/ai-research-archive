# Codex技能安装方法

## 问题
如何正确安装Codex技能并验证其有效性？

## 判断
Codex技能的安装需要结合VS Code使用，确保技能能够正常运行并完成预期功能。

## 规则
1. **下载技能包**：从官方渠道或可信来源下载Codex技能包。
2. **安装依赖项**：确保系统中已安装所有必要的依赖项和运行环境。
3. **配置环境变量**：根据技能要求，配置相应的环境变量。
4. **安装技能**：通过VS Code的扩展管理功能或命令行工具安装技能包。
5. **验证安装**：运行测试脚本或使用预定义的测试用例，确保技能功能正常。

## 例外
- **版本不兼容**：如果技能包与当前使用的VS Code版本不兼容，可能导致安装失败或功能异常。
- **依赖项缺失**：缺少必要的依赖项可能导致技能无法正常运行。

## 检查清单
- [ ] 确认下载的技能包来源可靠。
- [ ] 检查系统中是否已安装所有必要的依赖项。
- [ ] 配置正确的环境变量。
- [ ] 通过VS Code的扩展管理功能或命令行工具安装技能包。
- [ ] 运行测试脚本或使用预定义的测试用例，验证技能功能是否正常。

## 注意事项
- **待验证**：具体的安装步骤和验证方法可能因技能包的不同而有所变化，建议参考官方文档或技能包的README文件。
