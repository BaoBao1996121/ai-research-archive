# 审核包打包规则

## 问题
如何确保审核包的完整性和可追溯性？

## 判断
当前审核包打包流程需进一步完善，以确保打包结果的完整性和可追溯性。

## 规则
### 打包步骤
1. 收集所有相关文件
2. 生成审核包
3. 压缩审核包
4. 校验核心文件

### 校验规则
1. 核心文件完整性校验
2. 文件格式正确性校验
3. 打包时间戳记录
4. 打包人信息记录

## 例外
- 特殊情况下可手动打包，但需记录原因
- 校验失败时需及时通知相关人员

## 检查清单
1. 确认所有文件已收集
2. 确认审核包生成成功
3. 确认压缩无误
4. 确认核心文件完整性
5. 确认校验结果正常
6. 记录打包时间戳
7. 记录打包人信息

## 待验证
- 打包步骤中的具体文件收集范围
- 校验规则的具体实现方式
