# 多轮上下文摘要故障排查记录

**一句话结论：服务器版本多轮上下文摘要错误的根因在于 `summarizer.py` 的异步调度异常处理缺失和摘要触发条件的并发竞态，而非摘要逻辑本身。**

## 适用场景

当服务器版本的多轮对话上下文摘要显示错误、摘要缺失或摘要状态错乱时，使用本记录进行排查。

## 触发条件

- 服务器版本（非本地开发环境）的多轮对话摘要显示不正确
- 摘要内容与对话历史不匹配
- 部分轮次的摘要缺失
- 摘要状态在并发场景下出现错乱

## 核心步骤

### 1. 检查异步调度链路

```python
# 定位文件：services/summarizer.py
# 检查 fire_and_forget() 方法
def fire_and_forget(self, session_id: str, turn_count: int):
    # 问题：使用 asyncio.ensure_future 但未正确处理异常
    asyncio.ensure_future(self._summarize(session_id, turn_count))
    # 修复：需要添加异常捕获和日志记录
```

### 2. 检查异常处理

```python
# 修复方案：为 fire_and_forget() 添加异常处理
async def fire_and_forget(self, session_id: str, turn_count: int):
    try:
        await self._summarize(session_id, turn_count)
    except Exception as e:
        logger.error(f"摘要失败: session={session_id}, turn={turn_count}, error={e}")
        # 记录失败状态，避免静默丢失
```

### 3. 检查并发竞态条件

```python
# 定位文件：services/ws_session.py
# 问题：摘要触发条件 turn_count % 3 == 0 在并发场景下可能竞态
if turn_count % 3 == 0:
    # 多个 WebSocket 连接可能同时触发，导致摘要状态错乱
    await summarizer.fire_and_forget(session_id, turn_count)

# 修复：增加互斥锁
import asyncio
_summary_locks = {}

async def safe_trigger_summary(session_id: str, turn_count: int):
    if session_id not in _summary_locks:
        _summary_locks[session_id] = asyncio.Lock()
    
    async with _summary_locks[session_id]:
        if turn_count % 3 == 0:  # 双重检查，避免锁外判断后状态已变
            await summarizer.fire_and_forget(session_id, turn_count)
```
