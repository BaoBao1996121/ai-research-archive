# AI Agent 从零到生产 — 自学教程

> **给谁看的**：有 ML/DL/NLP 基础但学得不扎实、正在做 Agent 相关工作、想系统建立从概念到落地的完整认知的人。就是你自己。
>
> **教学方法**：融合 fast.ai 的 Whole Game（先跑完整游戏再问为什么）、Bruner 的螺旋式课程（核心概念在不同层次重复出现加深）、Bloom's Taxonomy（从记住→理解→应用→分析→创造递进）。每章遵循 WHY→WHAT→HOW→IF 结构。
>
> **素材来源**：本工作区 33+ 篇研究报告 + 8 个实验脚本 + 5 个 Skill + 1 个多 Agent 原型。教程不重复这些内容，而是在它们之上添加教学叙事层。

## 怎么用这个教程

1. **螺旋 1 必须按顺序**——Ch1→Ch2→Ch3→Ch4，每章建立在前一章基础上
2. **螺旋 2 和 3 可以按兴趣跳**——但建议至少读完 Ch5 再跳
3. **每章的"深入阅读"是可选的**——指向已有研究报告的具体章节，想深挖就去看
4. **代码一定要自己跑**——Agent 是"做中学"的领域，只看不做等于没学
