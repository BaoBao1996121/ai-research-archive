## 2. 状态词典

> 一句话结论：状态先说明“谁完成了什么”，避免用一个 Done 同时表示作者写完、代码通过和学习者掌握。

| 状态 | 适用对象 | 判定 |
|---|---|---|
| `planned` | 内容 | 已进入路线图，尚未产出 |
| `in-progress` | 内容 | 已有部分产物，文档结构、链接或源码锚点尚未全部验收 |
| `delivered` | 内容 | lesson、exercise、solution、源码映射齐备，文档结构、本地链接和源码锚点已通过交付检查；不自动表示 Lab 动态测试通过 |
| `learning` | 学习者 | 已开始 TRACE，但尚未通过四道掌握门 |
| `mastered` | 学习者 | M1 行为、M2 解释、M3 源码、M4 迁移全部通过，且已登记复习 |
| `revisit` | 学习者 | 延迟提取、迁移或校准暴露关键误解，需要回访 |
