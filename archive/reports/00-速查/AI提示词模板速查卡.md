# AI 提示词模板速查卡

> 基于 58 条 Copilot Chat 交互数据提炼。使用场景：发送消息前快速参考。

---

## 发送前 3 秒 Checklist

```
□ 做什么？（精确动词：创建/修改/检查/分析/对比/运行）
□ 关键约束？（格式/路径/范围/不要做什么）
□ 验收标准？（什么样的结果算完成）
```

---

## 模板 A · 完整任务 Brief（复杂任务必用）

```
你是{角色}。{一句话任务描述}。

## 输入
- {文件路径/数据来源/上下文引用}

## 产出要求
- 格式：{Markdown/代码/表格/Mermaid}
- 存入：{完整路径}
- 预期行数：{大约范围}

## 约束
- {明确不做什么}
- {遇到歧义时的处理策略}
- {敏感信息脱敏要求}

## 阶段（如需）
1. 先做 X → 交付物 A
2. 基于 A 做 Y → 交付物 B
```

**适用**：调研、方案设计、Skill 固化、批量操作

---

## 模板 B · 3 句话中等任务

```
{精确动词}{目标对象}，
{最关键的格式/范围约束}，
{产出路径或验收标准}。
```

**示例**：
- "检查 pattern-topics/ 下 25 个 md 文件的结构完整性，列出缺少必填字段的文件名和缺失项，输出为表格。"
- "将当前技术方案固化为 skill，遵循 Anthropic 设计哲学（Why > MUST），存入 skills/tech-proposal-writer/"

**适用**：修改、工具使用、中等复杂度的落地任务

---

## 模板 C · 探索性问题

```
关于 {具体主题}：
1. {具体问题 1}（期望回答形式：序列图/表格/一句话）
2. {具体问题 2}
3. {具体问题 3}
```

**反例**："详细给我介绍下"（太开放，Agent 不知道你已经了解哪些、想深入哪些）

---

## 模板 D · 复杂任务开头加确认

```
{任务描述}

开始执行前，先用 3 行复述你的理解，等我确认后再动手。
```

**适用**：预估 >20 turns 的任务

---

## 模板 E · 长会话重置锚点

```
当前进度确认：
- 已完成：{X, Y}
- 正在做：{Z}
- 接下来：{W}
是否正确？
```

**触发**：会话超过 20 turns 时主动插入

---

## 模糊词 → 精确词替换表

| 避免 | 替代 |
|------|------|
| 搞一下 | 修改 / 创建 / 检查 / 重构 |
| 看下 | 检查是否 X / 对比 A 与 B / 列出所有 Y |
| 试一下 | 执行 X 并检查输出是否包含 Y |
| 弄好 | 完成 X 并存入 Y 路径 |
| 详细介绍 | 用{图/表/代码}解释{具体方面} |
| 参考那个模板 | 严格遵循 {完整文件路径} 的格式 |
