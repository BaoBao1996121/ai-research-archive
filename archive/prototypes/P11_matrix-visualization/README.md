# P11 矩阵可视化

> 线性代数矩阵变换静态交互演示：用 Canvas 展示 2D/3D 矩阵对空间、基向量和几何体的影响。

## 打开方式

直接打开本目录下的 `index.html`，或从万宝楼点击“矩阵可视化”的“打开演示”。

## 功能

- 2D 变换：2×2 矩阵输入、旋转、缩放、镜像、剪切、动画演示。
- 3D 变换：3×3 矩阵输入、绕轴旋转、缩放、剪切、自动旋转视角。
- 指标展示：行列式、面积缩放、体积缩放。
