学习目标：看懂 Attention 的信息流

Transformer 可视化学习台

一句话结论：Transformer 的核心不是“记住词义”，而是让每个 token 动态决定从其他 token 取多少信息。先看信息怎么流动，再看 Q/K/V、mask、多头和位置编码。

本地依据：Obsidian R37 Vaswani 2017 Annotated Transformer

Self-Attention：给每个词补上下文

这一层不是直接输出答案，而是更新每个 token 的表示。比如“他”本来只是代词，看到“小明”以后，新表示里会带上“小明”的信息。

先看这个例子

句子：小明 把 苹果 放进 书包，因为 他 饿了。当前正在更新的词会向整句话“查资料”。

Attention(Q,K,V) = softmax((QKᵀ + mask) / temperature) V
1. Q：当前词发出检索请求
2. K：全句每个词都可被匹配Key 像“可被搜索的标签”，不是人工写死的标签，而是模型学出来的向量。
3. softmax：变成一行比例
4. V：按比例混合信息
这张表怎么看
行标题是“正在更新的词”，列标题是“可参考的信息来源”。每个数字是参考比例，一整行加起来等于 1。
容易误会的点
最大格子不是“模型输出的答案”，而是当前词最主要的信息来源。比如“他”看“小明”，意思是把“小明”的信息混进“他”的新表示。
为什么除以 √dₖ
点积维度越大，分数方差越大，softmax 越容易极端化。缩放的作用是让梯度更稳定。
当前注意力集中度

Causal Mask：生成模型不能偷看未来

第 i 行代表第 i 个位置正在预测下一个 token。GPT 类模型只能看自己和左边，上三角必须被设为 -∞。

没有 mask 会怎样
训练时模型直接看到答案，loss 会虚假变低，但真正生成时会崩。这类错误也叫 label leakage 或 future leakage。
公式层面
先把未来位置的 attention score 加上 -∞，再做 softmax。softmax(-∞)=0，所以未来 Value 不会参与加权和。
Encoder vs Decoder
BERT 这类 Encoder 通常双向看全句；GPT 这类 Decoder-Only 必须 causal mask，因为目标是自回归预测下一个 token。

Multi-Head：并行学习多种关注模式

切换不同头。每个头都在同一句话上看不同关系，最后 concat 后再线性融合。

一句话讲清
Multi-Head 不是“每个头看不同词维度”这么浅，而是在不同低维子空间里并行试探不同路由模式。
张量形状
(B,T,C) 先投影成 Q/K/V，再 reshape 为 (B,H,T,C/H)。H 个头并行算 attention，拼回 C 维。
工程取舍
头数更多不必然更好。头维度太小会损失表达，头数太多会增加调度和显存压力。

Position Encoding：让词序进入模型

没有位置信息，Self-Attention 更像处理一个集合。“我喜欢猫”和“猫喜欢我”的词袋相同，但语义完全不同。

句子 A
我喜欢猫

词序：我 → 喜欢 → 猫

句子 B
猫喜欢我

词序：猫 → 喜欢 → 我

原始 Transformer
用 sin/cos 不同频率给每个位置一个指纹，再加到 token embedding 上。
现代 LLM 常见做法
RoPE 把位置变成 Q/K 空间里的旋转。两个 token 的相对距离会体现在点积里，因此适合长上下文扩展。
学习顺序
先理解“无位置会变词袋”，再看 learned position 和 sin/cos；最后再展开 RoPE、ALiBi、长度外推。

Transformer Block：横向交流，再纵向加工

一个 Block 由 Attention、FFN、残差连接和 LayerNorm 组成。堆很多层，模型就能反复“交流、加工、保留原信息”。

输入 X：token embedding + position
↓
LayerNorm → Multi-Head Self-Attention
+
残差：保留原始通道，稳定深层训练
↓
LayerNorm → FFN，两层 MLP，逐 token 加工
+
残差：让梯度有近路可走
↓
输出：每个 token 都带着上下文的新表示
Attention 的职责
横向混合序列信息：这个词应该参考哪些词。
FFN 的职责
对每个位置独立做非线性变换：拿到上下文后自己加工。
残差 + LayerNorm
主要是训练稳定性。没有它们，几十层、上百层 Transformer 很难训。
