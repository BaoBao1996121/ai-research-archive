# 项目整合流程优化方法

## 触发规则
当项目整合后页面信息密度适中，但部分卡片展示价值偏弱时触发。

## 所需工具
- Obsidian插件
- Markdown编辑器
- 项目卡片模板

## 执行流程
1. **分析现有卡片**：评估当前卡片的信息密度和展示价值。
2. **设计优化方案**：确定需要优化的卡片，设计新的展示形式。
3. **实施优化**：根据设计方案调整卡片内容和布局。
4. **验证效果**：检查优化后的卡片是否提升了信息密度和展示价值。

## 证据规则
- 基于页面分析和实验数据。

## 失败模式
- 卡片信息过载，导致阅读困难。
- 卡片展示混乱，影响用户体验。

## 边界
- **适用范围**：适用于Obsidian Vault中的项目整合场景。
- **不适用情况**：不适用于信息密度已足够高的页面。
