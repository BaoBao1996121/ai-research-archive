# 启动器问题排查流程

## 触发规则
当尝试运行启动器.bat文件时遇到错误，无法启动launcher.py时触发。

## 所需工具
- 文本编辑器（如Notepad++）
- 命令行工具（CMD或PowerShell）
- 文件资源管理器
- Python解释器

## 执行流程
1. **检查文件路径**：
   - 确保.bat文件和launcher.py在同一目录下。
   - 检查.bat文件中引用的路径是否正确，避免使用相对路径。

2. **检查换行符**：
   - 打开.bat文件，检查是否存在换行符问题。
   - 使用文本编辑器将换行符转换为Windows标准的\r\n。

3. **检查文件权限**：
   - 确保当前用户有权限执行.bat文件和launcher.py。
   - 右键点击文件，选择“属性”检查权限设置。

4. **查看错误信息**：
   - 运行.bat文件时，注意观察错误提示。
   - 记录错误信息，便于后续分析。

5. **手动执行命令**：
   - 打开CMD，导航到launcher.py所在目录。
   - 手动执行.bat文件中的命令，逐步排查问题。

6. **检查Python环境**：
   - 确保Python解释器已正确安装并配置。
   - 在CMD中输入`python --version`验证Python版本。

7. **参考社区资源**：
   - 如果问题依旧，参考相关社区或论坛中的解决方案。
   - [待验证] 具体社区资源链接待补充。

## 证据规则
- 记录每次排查的步骤和结果。
- 保存错误信息和修改后的.bat文件内容。
- 确保所有操作有据可查，便于后续分析。

## 失败模式
- 错误信息无法识别或解决。
- 修改后问题依旧，无法启动launcher.py。
- 手动执行命令时出现新的错误。

## 边界
- 适用于.bat文件启动launcher.py的问题排查。
- 不适用于其他类型的启动器问题或非.bat文件相关的问题。
