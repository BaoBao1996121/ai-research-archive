# 评测流程优化

## 触发规则
当评测流程中发现自然度或调用次数相关问题时，触发本Skill。

## 所需工具
- 测试框架（如pytest）
- 数据建模工具（如Pandas/Scikit-learn）
- 代码编辑器

## 执行流程
1. **识别问题**：在评测过程中发现自然度或调用次数相关问题。
2. **修复测试用例**：针对问题修复相关测试用例。
3. **补充建模逻辑**：补充自然度代理和调用次数建模逻辑。
4. **验证改进**：验证改进后的评测流程。

## 证据规则
- 测试结果支持（待验证）
- 模型验证结果

## 失败模式
- **测试用例修复失败**：重新检查并修复测试用例。
- **模型逻辑错误**：重新审视并修正建模逻辑。
- **验证未通过**：重新调整并验证改进后的流程。

## 边界
- 仅适用于Judge A/B评测流程
- 不适用于其他评测模块
