# 飞书文档处理标准化命令模板

## 问题
飞书文档创建和操作缺乏统一的标准化命令模板，导致API版本和身份认证不一致，影响文档处理效率和一致性。

## 判断
需创建标准化命令模板，明确API版本和身份认证要求。

## 规则
1. **API版本**：所有文档操作必须显式指定API版本（如`v3`或`v4`）
2. **身份认证**：统一使用`OAuth2.0`认证方式，明确`access_token`获取和刷新流程
3. **命令结构**：模板需包含以下核心字段：
   - `doc_id`：文档唯一标识符
   - `version`：API版本号
   - `access_token`：认证令牌
   - `operation`：操作类型（`create`/`update`/`delete`/`get`）
   - `content`：文档内容（支持Markdown和富文本）
4. **错误处理**：统一错误码和错误信息格式，支持重试机制

## 例外
- 认证流程未完成的场景（待验证）
- 特殊文档类型（如表格、图片）需额外处理
