# 代码验证与测试流程

## 触发规则
当需要验证代码质量和稳定性时，触发此流程。

## 所需工具
- Git
- `npx repomix`
- 测试框架（如 pytest、Jest）
- 环境配置工具（如 Python venv、Node.js）

## 执行流程
1. **执行状态控制测试**
   - 使用测试框架运行状态控制测试。
   - 验证所有测试用例通过（如 `25 passed`）。
2. **会话门禁验证**
   - 检查会话门禁状态，确保所有安全和兼容性要求通过。
3. **代码质量检查**
   - 使用 `npx repomix` 验证代码质量。
   - 确保工作树 clean，无未提交更改。

## 证据规则
- 测试通过日志（如 pytest、Jest 输出）。
- 会话门禁通过状态文件。
- `npx repomix` 验证报告。

## 失败模式
- **测试未通过**：检查错误日志，修复代码后重新运行测试。
- **环境配置错误**：检查环境变量配置，确保 Python venv 和 Node.js 模块安装正确。
- **代码质量不达标**：根据 `npx repomix` 报告修复代码问题。

## 边界
- 适用于需要高代码质量和稳定性的项目。
- 不适用于快速原型开发或非关键代码验证。
