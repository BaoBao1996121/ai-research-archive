# 定时任务排查方法

## 触发规则
当定时任务无法按预期执行时，例如任务未运行、结果不符合预期或任务状态异常时，触发此技能。

## 所需工具
- PowerShell环境

## 执行流程
1. **检查任务是否存在**
   - 使用 `Get-ScheduledTask` cmdlet 查看所有已定义的定时任务。
   - 检查目标任务是否存在于任务列表中。

2. **查看任务状态**
   - 使用 `Get-ScheduledTaskInfo` cmdlet 获取目标任务的详细状态信息。
   - 检查任务的当前状态（如就绪、运行中、已停止等）。

3. **检查任务历史**
   - 查看任务的执行历史记录，确认最近一次运行的结果。
   - 检查是否有失败记录及其错误代码。

4. **查看错误日志**
   - 如果任务失败，查看相关的错误日志或输出信息。
   - 确定错误的具体原因，如权限问题、脚本错误或依赖项缺失。

## 证据规则
- 确保收集到任务的状态信息、执行历史和错误日志。
- 记录所有相关输出和日志内容，以便进一步分析。

## 失败模式
- **任务不存在**：目标任务未在系统中定义。
- **任务状态异常**：任务状态显示为停止、挂起或失败。
- **历史记录显示失败**：任务执行历史中存在失败记录。
- **错误日志存在**：任务执行过程中生成了错误日志或输出。

## 边界
- 适用于 Windows 操作系统，依赖 PowerShell cmdlet。
- 需要管理员权限以查看和管理定时任务。
- 任务依赖的外部资源（如网络服务或文件）可能影响任务执行，需额外检查。
