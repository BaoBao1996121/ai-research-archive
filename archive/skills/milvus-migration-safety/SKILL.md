# Milvus 迁移脚本加固

## 触发规则
当需要执行 Milvus 数据迁移任务，特别是从共享 Milvus 实例迁移到专用实例时，触发本安全校验流程。

## 所需工具
- Milvus 客户端库
- 迁移脚本
- 日志记录工具
- 测试框架

## 执行流程
1. **显式校验**：要求用户提供明确的 source 和 target 实例连接参数，包括地址、端口、访问密钥等。
2. **Dry-run 确认**：在实际迁移前，执行 dry-run 模拟迁移，展示将要执行的操作和潜在影响。
3. **日志记录**：记录关键操作日志，包括用户输入、校验结果和迁移步骤。

## 证据规则
- 迁移成功日志：记录迁移完成的确认信息。
- Dry-run 确认日志：展示模拟迁移的结果和潜在影响。
- 审计日志：记录所有关键操作和用户输入。

## 失败模式
- **未提供正确参数**：如果用户未提供正确的 source 或 target 参数，迁移将被阻止。
- **Dry-run 发现问题**：如果 dry-run 发现潜在问题，迁移将被中止。

## 边界
- 本 Skill 适用于专用 Milvus 实例的迁移，不适用于其他类型的数据迁移。
- 依赖于正确的连接参数配置，如果配置错误，Skill 无法发挥作用。
