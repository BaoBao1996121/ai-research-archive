# 语音分句器修复方案

## 触发规则
当TTS分句器导致音频截断时触发。

## 适用场景
语音合成过程中出现音频截断问题。

## 所需工具
- 分句器代码库
- 测试用例 `test_runner_keeps_one_character_tail_with_the_previous_sentence_for_complete_audio`
- 音频处理工具

## 执行流程
1. 分析分句器逻辑，识别导致截断的具体原因。
2. 修复排序逻辑，确保音频片段正确连接。
3. 更新测试用例，验证修复效果。
4. 部署修复后的分句器。

## 证据规则
- 测试用例通过。
- 音频片段无截断，完整输出。

## 失败模式
- 测试用例仍失败。
- 音频仍出现截断。

## 边界
- 仅适用于TTS分句器问题。
- 不处理其他语音处理问题。
