# 工具链安装问题排查

## 触发规则
当工具链安装失败，且错误提示与环境变量配置相关时触发。

## 所需工具
- PowerShell
- 系统环境变量编辑工具

## 执行流程
1. 检查系统环境变量配置：
   - 使用 `echo %PATH%` 查看当前环境变量路径
   - 确认工具链安装目录是否在 PATH 中
2. 验证工具链安装：
   - 使用 `winget --version` 和 `gh --version` 检查工具链是否可用
3. 检查依赖项：
   - 确认 .NET 运行时是否安装
   - 检查 PowerShell 版本是否符合要求
4. 检查权限配置：
   - 确认当前用户是否有写入工具链目录的权限
5. 检查网络配置：
   - 确认网络连接是否正常
   - 检查是否有防火墙或代理限制

## 证据规则
- 环境变量输出：`echo %PATH%`
- 工具链版本信息：`winget --version` 和 `gh --version`
- 依赖项版本信息：`.NET` 和 PowerShell 版本
- 权限日志：工具链目录的访问权限
- 网络状态：网络连接测试结果

## 失败模式
1. 环境变量配置正确，但工具链仍无法运行
2. 依赖项版本不兼容
3. 权限配置正确，但工具链仍无法安装
4. 网络配置正确，但工具链无法下载

## 边界
- 仅适用于 Windows 系统
- 适用于 winget 和 gh 等工具链
- 在复杂网络环境下可能需要额外排查
