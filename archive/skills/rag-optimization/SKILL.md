# 复合问题RAG性能优化方案

## 触发规则
当检测到复合问题RAG链路性能问题时，触发优化流程。具体包括以下情况：
- RAG链路成功率低于90%
- 延迟超过30秒
- LLM调用链路出现瓶颈

## 所需工具
- 性能分析工具：Prometheus、Grafana
- 代码优化工具：PyCharm、Black
- 数据分析工具：Jupyter Notebook

## 执行流程
1. **性能数据收集**
   - 使用Prometheus收集RAG链路性能数据
   - 重点关注LLM调用链路和生成链路的耗时

2. **性能分析**
   - 使用Grafana分析性能数据
   - 识别主要耗时环节和瓶颈

3. **优化实施**
   - 优化LLM调用链路，减少调用次数
   - 优化生成链路，提高生成效率

4. **验证**
   - 使用Jupyter Notebook验证优化效果
   - 确保成功率和延迟达到预期目标

## 证据规则
- 性能数据报告：Prometheus和Grafana生成的性能数据报告
- 优化前后对比结果：Jupyter Notebook生成的对比结果文档

## 失败模式
- 优化后性能未达预期：成功率仍低于90%或延迟未改善
- 引入新问题：优化后出现新的功能问题或性能问题

## 边界
- 适用于复合问题RAG链路性能优化
- 不适用于其他模块的性能优化
