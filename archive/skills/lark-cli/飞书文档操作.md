# 飞书文档操作速查卡

## 问题
如何正确使用 `lark-cli` 工具生成和发送飞书文档？

## 判断
飞书文档需包含现状、收益、风险和操作步骤，确保内容完整性和可追溯性。

## 规则
1. **文档生成**
   - 文档内容必须包含以下部分：
     - **现状**：当前问题或需求的背景描述。
     - **收益**：实施后的预期收益或价值。
     - **风险**：可能存在的风险及应对措施。
     - **操作步骤**：具体的操作流程和注意事项。
   - 使用 `lark-cli` 工具生成文档时，确保格式符合飞书文档规范。

2. **文档发送**
   - 发送前需检查文档内容是否完整，确保无遗漏关键信息。
   - 发送时需同步评论，确保接收方能够查看历史讨论。
   - 设置文档权限，确保仅授权人员可访问。

3. **API版本控制**
   - 使用最新版本的 `lark-cli` API，确保功能兼容性和稳定性。
   - 在文档中注明 API 版本信息，便于后续维护和追溯。

4. **权限管理**
   - 文档权限需与项目需求匹配，避免权限过大导致的安全风险。
   - 权限变更需记录在案，便于审计和追溯。

## 例外
- **紧急情况**：若因时间限制无法完整填写文档内容，需在文档中标注“待补充”并尽快完善。
- **权限冲突**：若权限设置失败，需立即联系飞书管理员协助处理。

## 检查清单
1. 生成文档时是否包含现状、收益、风险和操作步骤？
2. 发送前是否检查文档内容完整性？
3. 是否同步评论并设置正确权限？
4. 是否记录文档 ID 和版本信息？
5. 是否验证文档发送状态并收集接收方反馈？
